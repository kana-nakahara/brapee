Brappy 宅配買取サービス利用規約

株式会社楽楽（以下「当社」といいます。）は、当社が運営するブランド品買取サービス「Brappy（ブラッピー）」（以下「本サービス」といいます。）について、以下のとおり利用規約（以下「本規約」といいます。）を定めます。

第1条（適用範囲）

  1. 本規約は、本サービスを利用するすべてのお客様に適用されます。
  2. お客様は、本規約に同意したうえで本サービスを利用するものとします。
  3. 当社がウェブサイト等に掲載する利用案内、注意事項その他の個別条件は、本規約とともに適用されます。ただし、内容が異なる場合は、別途明示した個別条件を優先します。

第2条（サービス内容）

  1. 本サービスは、お客様からブランドバッグ、財布、時計、アクセサリーその他当社が取り扱う商品を宅配方式によりお預かりし、査定・買取を行うサービスです。
  2. 当社は、商品のブランド、状態、付属品、市場相場、再販売の可能性等を総合的に判断し、査定金額を提示します。
  3. 当社は、査定対象商品および取扱基準を変更することがあります。

第3条（利用資格）

本サービスを利用できるお客様は、以下の条件をすべて満たす方とします。

  1. 満18歳以上であること。
  2. 商品について適法な所有権および処分権限を有していること。
  3. 古物営業法その他関係法令に基づく本人確認に協力できること。
  4. 日本国内に住所を有し、当社が指定する本人確認および代金支払方法を利用できること。
  5. 反社会的勢力に該当せず、これらと関係を有していないこと。

法人のお客様については、当社が別途指定する法人確認書類、担当者の本人確認書類、委任状等の提出をお願いする場合があります。

第4条（申込みおよび宅配キット）

  1. お客様は、当社ウェブサイト、LINE公式アカウントその他当社が指定する方法により買取を申し込むものとします。
  2. 当社は、必要に応じて宅配キットをお客様に送付します。
  3. お客様は、商品が輸送中に破損しないよう適切に梱包するものとします。
  4. 商品の発送は、原則として当社が手配する集荷方法によるものとします。
  5. 当社の事前承諾なく発送された商品については、受領または査定をお断りする場合があります。

第5条（本人確認）

  1. 当社は、古物営業法その他関係法令に基づき、お客様の氏名、住所、生年月日等の確認を行います。
  2. 本人確認は、本人確認書類の提出、住所確認のための書留郵便等の送付、本人名義の金融機関口座への振込みその他法令上認められた方法により行います。
  3. 本人確認が完了しない場合、当社は買取を行いません。
  4. 提出された本人確認情報に虚偽、不備または疑義がある場合、当社は追加資料の提出を求め、または取引をお断りすることがあります。
  5. 法人のお客様については、法人の登記事項証明書、取引担当者の本人確認書類、委任状等、当社が指定する資料の提出を求めます。

第6条（取扱対象外商品）

当社は、以下の商品について買取をお断りすることがあります。

  1. 偽造品、模倣品、盗品その他違法性が疑われる商品
  2. 第三者の権利を侵害する商品
  3. 所有権や処分権限が確認できない商品
  4. 著しい破損、汚損等により再販売が困難な商品
  5. ノーブランド品その他当社の取扱基準に適合しない商品
  6. その他当社が買取対象外と判断した商品

第7条（査定）

  1. 当社は、商品到着後、商品の状態、真贋、付属品、市場価格等を確認し、査定金額を提示します。
  2. LINE、写真、メール等による事前査定は概算であり、実物査定の結果と異なる場合があります。
  3. 査定金額は、当社が別途明示する有効期間内に限り有効とします。
  4. お客様は、提示された査定金額を確認し、買取の承諾またはキャンセルを選択できます。
  5. 当社は、査定結果の根拠について可能な範囲で説明しますが、内部の価格算定方法、取引先情報等の開示義務を負うものではありません。

第8条（買取契約の成立）

  1. 買取契約は、当社が査定金額を提示し、お客様が当該金額での売却を承諾し、必要な本人確認等が完了した時点で成立するものとします。
  2. 買取契約成立後は、法令上認められる場合または当社が承諾した場合を除き、お客様都合によるキャンセルや商品の返還には応じられません。
  3. 買取契約成立後、商品の所有権は当社に移転します。
  4. お客様は、買取契約成立時点において、商品が第三者の権利の対象となっていないことを保証するものとします。

第9条（買取代金の支払い）

  1. 当社は、買取契約成立後、当社所定の期間内に、お客様本人名義の金融機関口座へ買取代金を振り込みます。
  2. 振込先情報の不備、金融機関の休業日、本人確認の未完了その他やむを得ない事情により、入金が遅れる場合があります。
  3. 原則として第三者名義の口座への振込みには対応しません。
  4. 法人取引の場合は、原則として当該法人名義の口座へ振り込みます。

第10条（キャンセルおよび商品の返送）

  1. お客様は、買取契約成立前であれば、査定結果を確認したうえで買取をキャンセルできます。
  2. キャンセルされた商品は、当社所定の方法により返送します。
  3. キャンセル時の返送料は【要確認：当社負担／お客様負担】とします。
  4. 商品の状態、法令上の制限、配送上の問題等により、通常の返送方法を利用できない場合があります。
  5. お客様と連絡が取れない場合や返送先が不明な場合、当社は合理的な方法で通知・保管し、その後の取扱いについて関係法令に従い対応します。

第11条（送料・査定料）

  1. 宅配キットの提供費用、当社指定の発送方法による送料および査定料は、原則として無料とします。
  2. 当社が指定しない方法による発送、特別な配送、その他追加費用が発生する場合は、事前にその負担についてお客様へ案内します。

第12条（配送中の事故等）

  1. お客様は、商品の破損を防ぐため、適切な梱包を行うものとします。
  2. 配送中の紛失、破損その他の事故については、配送業者の補償制度、事故原因および当社の責任の有無等を踏まえて対応します。
  3. 当社の故意または過失によりお客様に損害が生じた場合は、法令に従い責任を負います。
  4. 当社は、配送事故の調査に必要な情報の提供等について、お客様に協力をお願いすることがあります。

第13条（禁止事項）

お客様は、以下の行為を行ってはなりません。

  1. 虚偽の氏名、住所、本人確認情報等を申告する行為
  2. 盗品、偽造品、第三者の所有物等を不正に売却する行為
  3. 本サービスの運営を妨害する行為
  4. 当社または第三者の権利・利益を侵害する行為
  5. 法令または公序良俗に反する行為
  6. その他当社が合理的な理由により不適切と判断する行為

第14条（寄付活動）

  1. 当社は、社会貢献活動の一環として、Brappyの買取成立金額の1％相当額を、公益社団法人アニマル・ドネーションへの寄付に充てます。
  2. 寄付は当社が行うものであり、お客様の買取代金から別途控除するものではありません。
  3. 寄付の実施方法、時期および活動報告等については、当社ウェブサイト等で案内します。

第15条（個人情報の取扱い）

当社は、本サービスに関連して取得した個人情報を、当社が別途定めるプライバシーポリシーおよび個人情報保護法その他関係法令に従って適切に取り扱います。

第16条（サービスの変更・停止）

当社は、システム障害、災害、法令改正その他やむを得ない事情により、本サービスの全部または一部を変更・停止することがあります。その場合、可能な限り事前に案内します。

第17条（損害賠償）

当社またはお客様が、本規約違反その他自己の責めに帰すべき事由により相手方に損害を与えた場合は、関係法令に従い、その損害について責任を負うものとします。

第18条（規約の変更）

当社は、民法その他関係法令に従い、本規約を変更することがあります。変更する場合は、変更内容および効力発生日を当社ウェブサイト等で周知します。

第19条（準拠法および管轄）

  1. 本規約の準拠法は日本法とします。
  2. 本サービスに関して紛争が生じた場合、法令上認められる範囲で、東京地方裁判所または東京簡易裁判所を第一審の合意管轄裁判所とします。
